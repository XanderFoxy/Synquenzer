- **Audio-Ebene nach Noten-Änderung schneller neu gerechnet, gleiches Ergebnis:** Muss eine umgesetzte Audio-Ebene nach einer Noten-Änderung ganz neu gerechnet werden, werden nur noch die Abschnitte um die geänderten Noten wirklich neu gerechnet; alle anderen Abschnitte kommen Bit für Bit unverändert aus einem Zwischenspeicher. Der Klang bleibt exakt gleich.
  Tests: 40-s-Lied mit 49 Noten, je 2 Läufe abwechselnd (iPhone hochkant), Hash der Ebene vorher = nachher in allen 5 Schritten; 1 Note geändert, ganz rechnen 2697 → 1116 ms, 2 Noten 2951 → 1028 ms, 1 Note zeitlich verschoben 2766 → 976 ms; erstes Anlegen 3368 → 3565 ms (füllt den Speicher), normaler Bereichs-Weg 168 → 206 ms; 20-s-Lied 1342 → 597 ms; Seite ohne Fehler.

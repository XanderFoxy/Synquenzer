# Neu: DAW-Projekt transponieren (⇅½)
- Öffnen: ≡ Menü › Export › Audio/MIDI importieren › Datei wählen (.cbp). Im Blatt unter „Transponieren“ ist „Halbton“ schon gewählt.
- Dann unten auf der Tastatur ⇅ TRANSPONIEREN tippen: Taste C = Original, jede andere Taste spielt den ganzen Song genau in ihrer Tonart.
- Oben im Feld TRÄGER steht, was passiert, z. B. „D +2 → D-Dur“.
- Alle Synth-Spuren zeigen „⇅½“, auch leere und neue. So klingt alles zusammen.
- Taste ⇅½ unter der Spur antippen: ⇅½ → fest → ⇅ (folgt den Akkorden).
- „Song transponieren“ und die Rückung je Teil im Song wirken dazu. Fotos: fotos/xla3-p-blatt.png, xla3-p-matrix.png, xla3-l-matrix.png, xla4-l-hilfe.png

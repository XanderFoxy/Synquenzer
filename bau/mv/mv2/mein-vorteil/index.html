Push auch bei geschlossener Seite
  1. In GitHub Settings → Secrets and variables → Actions öffnen (Knopf unten).
  2. New repository secret: Name BTC_EINSTIEG, Wert dein Einstiegspreis in € (z. B. 61500). Genauso ETH_EINSTIEG. Optional BTC_SCHWELLE_PROZENT / ETH_SCHWELLE_PROZENT (z. B. 5 = erst ab +5 %).
  3. Actions → Krypto-Wecker → Run workflow einmal starten. Danach prüft er alle 30 Minuten und schickt einmal eine Nachricht über dein ntfy-Thema, wenn ein Coin in den Gewinn dreht.

Die Nachricht nennt nur den Kurs – nie deinen Einstieg (das ntfy-Thema ist nicht geheim).
